# WindTool 资产

`WindTool-WindSource.pmx` 由 `generate_wind_source_pmx` 构建目标生成，不手工维护二进制内容。

模型作者：克里斯提亚娜。PMX 的模型信息固定显示为 `作者：克里斯提亚娜`。

- 第一根骨骼 `WT_Source`：位置为风源中心，本地 `+X` 为风向。
- 表情 `風場範囲`（`WT_Radius`）：局部半径为 `2 + 78 * 权重`。
- 表情 `風力倍率`（`WT_Strength`）：风力倍率为 `4 * 权重`，并乘在面板基础强度之上；`25% = 1x`，`0% = 0x`。
- 表情 `減衰核心`（`WT_Falloff`）：核心比例为 `0.05 + 0.90 * 权重`。
- 蓝色三轴球形笼显示 PMX 局部模式的实际作用半径，橙色箭头显示方向和强度，黄色刻度显示核心比例。

在 WindTool 的 `风源` 下拉框选择 `PMX 局部` 后，可将三个表情先设为约 `23% / 25% / 33%`。本地显示名使用 MMD 9.31 可稳定处理的 CP932 兼容字形，插件识别使用括号中的稳定英文标识。三个表情和控制骨骼都可以直接在 MMD 中注册关键帧。插件只读取 MMD 9.31 已确认的骨骼世界矩阵和表情权重；控制器缺失时局部风为零，不自行解析或修改 PMM。

同一个 PMX 可以重复加载，WindTool 会按模型表顺序同时读取最多 `16` 个控制器。每个副本独立提供中心、方向、范围、倍率和核心比例；覆盖同一刚体时做向量叠加，同向增强、反向抵消，最终统一限幅和平滑后只写入一次 Bullet 总力。
